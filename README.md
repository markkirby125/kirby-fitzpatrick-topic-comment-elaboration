## Core Patterns

- **Topic Comment Elaboration**: Topic vs Comment syntax: place known system state or familiar terminology in the subject position (Topic) before delivering novel architecture details or mutations (Comment).
- **Practical Application**: Documenting classes, modules, and API services without jumping topics.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
